# AGENTS 项目档案生成 · 入口文件

> 用法：把本文件拖给 Agent 工具，或把内容贴进对话。读到本文件就直接按下面四步做，不要先问"要不要开始"。

1. 读 `_template\AGENTS.protocol.md`（当前项目根下的模板协议）。
2. 按它的第 1–3 节：勘察目录 → 一次问 ≤5 题 → 用 `_template\AGENTS.templates\generated.md` 生成正式档案。
3. 先写 `<工作目录>\AGENTS.md.tmp`（不会被自动加载）；自检通过后改名成 `AGENTS.md`（已存在同名文件则先备份为 `AGENTS.md.bak.<日期>`）。改名失败就保留 `.tmp` 并给出命令。
4. 跑协议 §5 自检，回 3–5 行摘要 + 一句"有要改的吗"。
