# 模块：Markdown 文档集

> 仅当 PROFILE「技术栈」为 Markdown 文档时使用。未启用时不要读本文件，也不要把内容写进生成物。

## 环境与版本

- Markdown 源文件，UTF-8 无 BOM；无构建工具。
- 校验用 bash `wc` / `grep`，不引入其他检查工具。

## 目录与构建

- 目录划分按 PROFILE「组织方式」；默认：按职责分层（协议 / 规则库 / 空壳），不按日期堆文件。
- 构建命令：无；校验命令用 PROFILE「构建验证」那一行。

## 代码约束

- 行数按 PROFILE「硬约束」；超出必须重写，禁止删内容凑数。
- 强度词只用「必须 / 禁止 / 只」；不写「应该 / 尽量 / 建议」。
- 中文正文；技术名词保留原文；不写口号式形容词。

## 常见坑

- 编辑器默认存 UTF-16 / GBK，写入时必须显式 UTF-8 无 BOM。
- `README.md` 只给人看，禁止整份抄进产物。
- 同一事实只写一处；写多处必然漂移。
