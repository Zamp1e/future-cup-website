# 模块：Python 3 练习

> 仅当 PROFILE「技术栈」为 Python 3 时使用。未启用时不要读本文件，也不要把内容写进生成物。

## 环境与版本

- Python 3.10+；标准库优先；无第三方依赖时直接跑，不建虚拟环境。

## 目录与构建

- 目录划分按 PROFILE「组织方式」；一个任务一个 `.py`，入口 `main.py`。
- 构建命令：无；运行命令写进 PROFILE「构建验证」，如 `python main.py < input.txt`。

## 代码约束

- 缩进 4 空格；不用 `import *`；模块级不写副作用代码，统一 `if __name__ == "__main__":`。
- 第三方库先确认：题目没说明时只用标准库。
- 浮点输出按题目样例对齐位数，用 `f"{x:.2f}"` 或 `round(x, n)`。
- 输入按题目约定：`sys.stdin` 读全部，或 `input()` 逐行；大数据量用 `sys.stdin.buffer`。

## 常见坑

- Windows 终端默认 GBK，`print` 中文前先确认编码；输出重定向时显式 `encoding="utf-8"`。
- `dict` / `set` 无序，按题目要求显式排序。
- 整除用 `//`，浮点除用 `/`；负数取整方向要验证。
