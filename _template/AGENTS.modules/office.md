# 模块：Office 文档（Word / Excel / PowerPoint 报告）

> 仅当交付物含报告、且目录里确有 Office 文档模板时使用。未启用时不要读本文件。

## 开工前

- 先探测办公工具是否可用；不可用**先提醒用户安装/启用插件并等确认**，禁止降级去手搓 COM / OLE 解析。

## 顺序（固定）

探测 → 打开 → 读原稿 → 改 → 渲染复查 → 保存。

## 改法

- 正文常在表格单元格里：内容写进对应单元格，不要落到表格后面的文档末尾。
- 跨页表格 `KeepWithNext` / `KeepTogether` 基本无效；「标签 + 截图」合并成一段，或去掉标签。
- 图片宽度留余量：单元格 450pt 时用 110pt。
- 只动指定章节；改前备份原稿（`*.docx.bak`）。

## 复查

- 整篇总览 + 关键页逐页看：是否出框、是否有空页、字体字号是否一致、公式是否仍是纯文本。
- 复查用文档自身渲染，不用别的转换器代替。

## 平台细节

- （Windows）PowerShell 脚本必须存为 UTF-8 with BOM；5.1 会按 GBK 解析，中文匹配会静默失效。
