# 模块：TypeScript / Node 练习

> 仅当 PROFILE「技术栈」为 TypeScript / Node 时使用。未启用时不要读本文件。

## 组织

- 任务划分按 PROFILE「组织方式」（默认一个任务一个文件，末尾直接执行并打印结果）。
- `main.ts` 汇总 `import`。
- 默认每个练习目录带 `README.md` + `screenshots/`。

## 输出

- 输出文字逐字对齐题目示例。
- 截断取整用 `Math.floor(x * 10) / 10`；`toFixed` 会四舍五入，慎用。

## 运行

- 直接 `node <file>.js` 或 `npx ts-node <file>.ts`；运行命令写进 PROFILE 的「构建验证」。
